# v16.95 — Visual Comfort Polish

Pembaruan visual ringan untuk membuat UI lebih nyaman dilihat tanpa mengubah alur fitur.

- Mengurangi glow latar dan efek kaca yang terlalu kuat agar mata lebih fokus.
- Merapikan keterbacaan teks, line-height, dan kontras label sekunder.
- Membuat permukaan kartu data lebih tenang dan tetap solid untuk angka penting.
- Menyamakan fokus keyboard, target sentuh, safe area, serta dukungan reduced motion/transparency.
- Menjaga dukungan tema terang dan gelap.
